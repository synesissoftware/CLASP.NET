## Q1: "How do I install this library?"

Install via **NuGet**:

```bash
dotnet add package CLASP.NET
```

See [INSTALL.md](./INSTALL.md) and [README.md](./README.md) for usage.


## Q2: "Why is the SemVer 0.27.0 after Framework 0.26.x?"

Framework-era releases used a 4-part assembly version culminating in
**0.26.165.1**. The SDK-style line adopts SemVer and continues that minor
series as **0.27.0** rather than resetting to **0.1.0**.
